
The 7 layers OSI Model
7 - APPLICATION
purpose/function - Interacts directly with software applications to provide network services. Example: HTTP, HTTPS, FTP, DNS, SMTP
Vulnerability/Attack - 
1. when there is flaws in software code 
2. Phishing 
3. SQL Injection (SQLi) 
4. Cross-Site Scripting (XSS) 
5. input validation
Defensive Measures - 
1. Deploy a Web Application Firewall (WAF) to filter malicious HTTP traffic. 
2.Implement strict input validation and parameterized queries to block SQLi and XSS. 
3.Conduct regular static and dynamic application security testing (SAST/DAST).

6 - PRESENTATION
purpose/function - Translates, encrypts, and compresses data so the application layer can read it. Exampls: SSL/TLS, JPEG, MP4. 
Vulnerability/Attack - 
1. Misconfigured encryption 
2. malicious file formats. 
3. SSL/TLS Downgrade Attacks (e.g., POODLE) 
4. malicious code execution via corrupted image/video formats 
5. data interception due to weak encryption.
Defensive Measures - 
1.Enforce modern cryptographic standards by disabling legacy protocols (like SSL v3, TLS 1.0, and TLS 1.1) and using only TLS 1.3 or secure configurations of TLS 1.2. 
2.Implement strict file-type verification and sandbox environments to inspect media files before processing.

5 - SESSION
purpose/function - To opens, maintains, and closes communication sessions between devices, Examples: Login sessions, remote procedure calls, SMB. 
Vulnerability/Attack - 
1. Weak session tokens 
2. lack of session timeouts and predictable session IDs.
3. Session Hijacking, Man-in-the-Middle (MitM)
4. Session Replay attacks where an attacker steals a valid user session cookie to bypass authentication.
Defensive Measures -  
1. Enforce short session timeouts and re-authentication for sensitive actions. 
2. Tie sessions to specific user attributes like IP addresses or TLS fingerprints to prevent hijacking.

4 - TRANSPORT
purpose/function - Handles end-to-end data delivery, error checking, and flow control using segments. Examples: TCP (reliable), UDP (fast). 
Vulnerability/Attack - 
1. Open ports 
2. predictable TCP sequence numbers 
3. Unauthenticated stateful connections.
4. SYN Flood (exhausting server resources by leaving TCP handshakes incomplete), 
5. Smurf attacks, UDP floods, and port scanning.

Defensive Measures - 
1. Configure firewalls to implement SYN cookies to mitigate SYN flood attacks. 
2. Use rate-limiting on open ports and close any unused ports. 
3. Deploy network firewalls capable of stateful packet inspection to drop malformed or out-of-sequence segments.

3 - NETWORK
purpose/function - Determines physical routing and moves packets across different networks using logical addresses. Examples: IP (IPv4, IPv6), ICMP.
Vulnerability/Attack - 
1. Lack of built-in authentication for IP addresses and routing protocols.
2. IP Spoofing (faking the sender's IP address). 
3. ICMP Flood (Ping flood)
4. BGP route hijacking 
5. packet sniffing.
Defensive Measures - 
1. Implement anti-spoofing filters (like BCP 38 or Unicast Reverse Path Forwarding) to block packets with forged IP addresses. 
2. Use IPsec VPNs to encrypt data packets in transit. 
3. Deploy Next-Generation Firewalls (NGFW) and cloud-based DDoS mitigation services (e.g., Cloudflare) to absorb ICMP/Ping floods.

2 - DATA LINK
purpose/function - Manages node-to-node data transfer and corrects physical errors using MAC addresses. Examples: Ethernet, Wi-Fi (802.11), switches. 

Vulnerability/Attack - 
1. Implicit trust within a local area network (LAN) 
2. Unauthenticated hardware addresses.
3. ARP Spoofing/Poisoning (linking an attacker's MAC address to a legitimate IP)
4. MAC Flooding (overwhelming switches to force them into a vulnerable state)
5. VLAN hopping.
Defensive Measures -
1. Enable Dynamic ARP Inspection (DAI) and DHCP Snooping on network switches to stop ARP spoofing. 
2. Implement Port Security to limit the number of MAC addresses allowed per switch port. 
3. Preventing MAC flooding. 
4. Configure proper VLAN tagging 
5. Disable unused ports to prevent VLAN hopping.

1 - PHYSICAL
purpose/function - Transmits raw binary bitstreams (electrical, optical, or radio signals) over physical hardware media. Examples: Cables, connectors, radio frequencies
Vulnerability/Attack - 
1.Unsecured physical access to hardware, cables, and unprotected wireless frequencies.
2. Wiretapping/Sniffing (splicing or listening into physical copper/fiber cables)
3. Signal Jamming (disrupting wireless frequencies), 
4. physical destruction, or theft of hardware.
Defensive Measures - 
1. Restrict physical access to server rooms, wiring closets. 
2. Data centers using biometrics, badges, and CCTV cameras. 
3. Shield cables in protective conduits to prevent wiretapping. 
4. Use spread-spectrum technologies or automated frequency monitoring to detect and mitigate wireless signal jamming.
